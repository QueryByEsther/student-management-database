# Student Management Database 

## Project Overview

This project is a relational database built using PostgreSQL as part of my database management learning journey through freeCodeCamp.

It demonstrates how student information, academic majors and courses can be organised and connected using relational database concepts.

## Database Structure

The database contains four main tables:

- **Students:** Stores student records, including names, majors and GPA.
- **Majors:** Stores available academic majors.
- **Courses:** Stores available courses.
- **Majors_Courses:** Connects majors with their associated courses.

## Technologies Used

- CSV files
